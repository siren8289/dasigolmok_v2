## 검증 목적

## 사전조건

행정동 업종 추천 모듈 준비; 입력 사례 'ML 예측 매핑'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

## 실행 절차

1. pred=[3,5,8] 준비
2. 행정동 업종 추천의 'ML 예측 매핑' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교
