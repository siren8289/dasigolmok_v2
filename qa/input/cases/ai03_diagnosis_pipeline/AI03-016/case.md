## 검증 목적

상권 진단 오케스트레이션에서 '상권변화명' 단일 조건을 검증하여 입력·처리·출력·예외가 일치하는지 확인

## 사전조건

상권 진단 오케스트레이션 모듈 준비; 입력 사례 '상권변화명'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

change_name=상권축소

## 실행 절차

1. change_name=상권축소 준비
2. 상권 진단 오케스트레이션의 '상권변화명' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교
