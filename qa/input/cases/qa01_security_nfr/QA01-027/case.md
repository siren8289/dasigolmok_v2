## 사전조건

보안·성능·사용자 품질 모듈 준비; 입력 사례 '백업·복구'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

PostgreSQL volume

## 실행 절차

1. PostgreSQL volume 준비
2. 보안·성능·사용자 품질의 '백업·복구' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교

## 기대 결과

백업 복원 무결성

## 판정 기준

RISK: 검증 불가/정책 미정/잠재 위험
