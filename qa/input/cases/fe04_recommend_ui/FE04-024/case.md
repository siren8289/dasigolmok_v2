## 검증 목적

## 사전조건

업종 추천 화면 모듈 준비; 입력 사례 '옵션 실패 후 추천'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

옵션 GET 오류

## 실행 절차

1. 옵션 GET 오류 준비
2. 업종 추천 화면의 '옵션 실패 후 추천' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교

## 기대 결과

유효한 기존 값일 때만 요청/오류 안내

## 판정 기준

PASS: 유효한 기존 값일 때만 요청/오류 안내 관찰 및 예상치 밖 부작용 없음
FAIL: 예상 불일치·예외 누락·데이터 오염
RISK: 검증 불가/정책 미정/잠재 위험
