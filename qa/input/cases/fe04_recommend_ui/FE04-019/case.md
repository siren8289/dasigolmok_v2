## 검증 목적

업종 추천 화면에서 '추천 재요청' 단일 조건을 검증하여 입력·처리·출력·예외가 일치하는지 확인

## 사전조건

업종 추천 화면 모듈 준비; 입력 사례 '추천 재요청'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

지역 변경 후 다시 누름

## 실행 절차

1. 지역 변경 후 다시 누름 준비
2. 업종 추천 화면의 '추천 재요청' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교

## 기대 결과

최신 지역 결과로 교체

## 판정 기준

PASS: 최신 지역 결과로 교체 관찰 및 예상치 밖 부작용 없음
FAIL: 예상 불일치·예외 누락·데이터 오염
RISK: 검증 불가/정책 미정/잠재 위험
