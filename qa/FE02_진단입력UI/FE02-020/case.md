## 검증 목적

진단 페이지 입력·셀렉트에서 '옵션 요청 실패' 단일 조건을 검증하여 입력·처리·출력·예외가 일치하는지 확인

## 사전조건

진단 페이지 입력·셀렉트 모듈 준비; 입력 사례 '옵션 요청 실패'에 필요한 fixture/mock 구성; 외부 API는 테스트 더블 사용

## 테스트 입력값

GET /api/options 503

## 실행 절차

1. GET /api/options 503 준비
2. 진단 페이지 입력·셀렉트의 '옵션 요청 실패' 조건 실행
3. 반환값·상태코드·로그·부수효과를 기대결과와 비교

## 기대 결과

'목록을 불러오지 못했습니다' 또는 구체 메시지를 표시

## 판정 기준

PASS: '목록을 불러오지 못했습니다' 또는 구체 메시지를 표시 관찰 및 예상치 밖 부작용 없음
FAIL: 예상 불일치·예외 누락·데이터 오염
RISK: 검증 불가/정책 미정/잠재 위험
