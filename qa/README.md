# dasiGolmok v2 QA MASTER

973건을 44개 섹션 폴더로 나누고, 섹션마다 테스트를 실행한 뒤 결과를 케이스 카드에 기록한다.

각 케이스 카드 `case.md`의 실행 기록은 원본 시트의 O·P·Q 열이다.

| 열 | 의미 |
| --- | --- |
| 실행 상태 (O) | PASS, FAIL, RISK, 미실행 |
| 실제 결과/증적 (P) | 실행에서 관찰한 값 |
| 결함 ID (Q) | FAIL일 때만 `DEF-<TC ID>` |

- PASS는 그 케이스를 실제로 실행해 기대 결과가 관찰된 경우만 적는다.
- FAIL은 실행 결과가 기대와 다를 때다. 개선제안이라도 방어가 없으면 FAIL이다.
- RISK는 이 환경에서 측정을 끝내지 못한 경우다. 레이아웃 픽셀, 운영 부하, 외부 장애 재현이 여기 해당한다.
- 정적 읽기만으로 결함을 단정하지 않는다.

프론트 케이스는 `cd front && npm test` 로 다시 실행한다. 나머지 자동화는 `qa/automation/` 아래에 섹션별로 둔다.
